# ATRIUM MTL — mode d'emploi simple

## Ouvrir le site
1. Gardez le fichier `index.html` **et** le dossier `assets` ensemble, dans le même dossier.
2. Double-cliquez sur `index.html` : le site s'ouvre dans votre navigateur (Chrome, Safari, Edge, Firefox).
3. Une connexion Internet est nécessaire pour voir les photos.

## Ce qu'il y a dedans
- `index.html` — tout le site (mise en page, animations, menu) dans un seul fichier.
- `assets/fonts/` — les deux polices (Archivo et Inter, licence libre SIL OFL 1.1).

## Changer un texte
Ouvrez `index.html` avec un éditeur de texte (Bloc-notes, TextEdit), cherchez la phrase avec Ctrl+F (Cmd+F sur Mac), modifiez-la et enregistrez.

## Sur téléphone et tablette
Le site s'adapte tout seul. Le bouton **Menu** (en haut à droite) ouvre tous les liens, les numéros de téléphone et le bouton **Tickets**. **Close**, la touche Échap ou un clic à côté le referment.
